Αρχική Μέρος Γ 1D Αναζήτηση

Μονοδιάστατη Γεωμετρική Αναζήτηση (1D Range Search)

ΣΙΓΟΥΡΑ ΘΑ ΠΕΣΕΙ: Κατασκευή και διερεύνηση 1D ή 2D δέντρου αναζήτησης. Η 1D αναζήτηση είναι η βάση για τα kd-trees και range trees!

1. Εισαγωγή (Διαισθητικά)

👋 Εισαγωγή για Αρχάριους:

Φανταστείτε έναν τηλεφωνικό κατάλογο με ονόματα ταξινομημένα αλφαβητικά. Αν θέλετε να βρείτε όλα τα ονόματα από "Κώστας" έως "Νίκος", δεν χρειάζεται να διαβάσετε ολόκληρο τον κατάλογο!

Η ιδέα: Βρίσκετε πρώτα το σημείο όπου "χωρίζεται" το διάστημα (π.χ. πού τελειώνουν οι λέξεις πριν το "Κ" και αρχίζουν αυτές μετά το "Ν"), και μετά συλλέγετε μόνο τα σχετικά στοιχεία.

Ορισμός: 1D Range Query Δεδομένου ενός συνόλου σημείων $P = \{p_1, p_2, ..., p_n\}$ στην ευθεία και ενός διαστήματος $[x, x']$, βρες όλα τα σημεία $p \in P$ τέτοια ώστε $x \le p \le x'$.

Η naive λύση (έλεγχος κάθε σημείου) έχει πολυπλοκότητα $O(n)$. Με τη χρήση ισοζυγισμένου δυαδικού δέντρου αναζήτησης (ΔΔΑ), μπορούμε να πετύχουμε $O(\log n + k)$, όπου $k$ τα σημεία στην απάντηση.

2. Δομή: Ισοζυγισμένο ΔΔΑ με Δεδομένα στα Φύλλα

Βασική Ιδέα
  • Φύλλα: Αποθηκεύουν τα πραγματικά σημεία (ταξινομημένα αριστερά→δεξιά)
  • Εσωτερικοί κόμβοι: Αποθηκεύουν την τιμή διαχωρισμού (splitting value) - τη μέγιστη τιμή του αριστερού υποδέντρου
  • Ισορροπία: Το δέντρο είναι ισοζυγισμένο, άρα ύψος $O(\log n)$

Παράδειγμα: Για τα σημεία $\{2, 5, 8, 12, 15, 19, 23, 27\}$:

              [12]
            /      \
         [5]        [19]
        /   \      /    \
      [2]   [8]  [15]   [23]
      / \   / \   / \    / \
     2   5 8  12 15 19  23 27

Κάθε εσωτερικός κόμβος περιέχει τη μέγιστη τιμή του αριστερού του υποδέντρου.

3. Κόμβος Διχασμού (Split Node)

Ορισμός: Split Node Ο κόμβος διχασμού για ένα διάστημα $[x, x']$ είναι ο κόμβος $v$ τέτοιος ώστε:
  • Τα μονοπάτια προς $x$ και $x'$ χωρίζονται στον $v$
  • Ισοδύναμα: $x \le v.value < x'$ (η τιμή του κόμβου είναι μεταξύ των ορίων)
Ο split node είναι ο "πρόγονος" που περιέχει όλα τα σχετικά σημεία.

Ψευδοκώδικας: FIND-SPLIT-NODE

function FIND-SPLIT-NODE($T, x, x'$)

  • Είσοδος: Δέντρο $T$, διάστημα $[x, x']$
  • Έξοδος: Κόμβος διχασμού $v$
  1. $v \leftarrow T.root$
  2. Όσο ο $v$ δεν είναι φύλλο και ($x' \le v.value$ ή $x > v.value$):
    • Αν $x' \le v.value$: $v \leftarrow v.left$
    • Αλλιώς: $v \leftarrow v.right$
  3. Επίστρεψε $v$
💡 Διαίσθηση: Ακολουθούμε το δέντρο προς τα κάτω. Αν και τα δύο όρια πάνε αριστερά (ή δεξιά), συνεχίζουμε εκεί. Μόλις χωρίζονται, σταματάμε - βρήκαμε τον split node!

4. Αλγόριθμος 1D Range Query

⚠️ ΠΡΟΣΟΧΗ - Σύμβαση Ορίων:
Στις διαφάνειες και εξετάσεις: αριστερά → ≤ (όχι <).
Δηλαδή στο αριστερό υποδέντρο ακολουθούμε αν $x \le v.value$, όχι $x < v.value$.

Ψευδοκώδικας: 1D-RANGE-QUERY

function 1D-RANGE-QUERY($T, x, x'$)

  1. $v_{split} \leftarrow$ FIND-SPLIT-NODE($T, x, x'$)
  2. Αν ο $v_{split}$ είναι φύλλο:
    • Έλεγξε αν το σημείο του είναι μέσα στο $[x, x']$
  3. Αλλιώς:
    • // Αριστερό μονοπάτι
      $v \leftarrow v_{split}.left$
      Όσο ο $v$ δεν είναι φύλλο:
      • Αν $x \le v.value$:
           Ανάφερε ΟΛΑ τα σημεία στο $v.right$
           $v \leftarrow v.left$
      • Αλλιώς: $v \leftarrow v.right$
      Έλεγξε το φύλλο $v$.
    • // Δεξί μονοπάτι (συμμετρικά)
      $v \leftarrow v_{split}.right$
      Όσο ο $v$ δεν είναι φύλλο:
      • Αν $x' > v.value$:
           Ανάφερε ΟΛΑ τα σημεία στο $v.left$
           $v \leftarrow v.right$
      • Αλλιώς: $v \leftarrow v.left$
      Έλεγξε το φύλλο $v$.
Πολυπλοκότητα
  • Χρόνος: $O(\log n + k)$ όπου $k$ = αριθμός σημείων στην απάντηση
  • Χώρος: $O(n)$
Η $\log n$ αντιστοιχεί στο ύψος του δέντρου (εύρεση split node + 2 μονοπάτια).

5. Λυμένο Παράδειγμα

Παράδειγμα: 1D Range Query [6, 20]

Δεδομένα: $P = \{2, 5, 8, 12, 15, 19, 23, 27\}$, Query: $[6, 20]$

Βήμα 1: Κατασκευή Δέντρου
              [12]          ← root
            /      \
         [5]        [19]
        /   \      /    \
      [2]   [8]  [15]   [23]
      / \   / \   / \    / \
     2   5 8  12 15 19  23 27
Βήμα 2: Εύρεση Split Node
  • $v = [12]$ (root)
  • Έλεγχος: $x' = 20 \le 12$? ΟΧΙ. $x = 6 > 12$? ΟΧΙ.
  • Άρα $[12]$ είναι ο split node!
Βήμα 3: Αριστερό Μονοπάτι (από [12] αριστερά)
  • $v = [5]$: $x=6 \le 5$? ΟΧΙ → πάμε δεξιά
  • $v = [8]$: $x=6 \le 8$? ΝΑΙ →
    • Αναφέρουμε ΟΛΟ το δεξί υποδέντρο: $\{12\}$
    • Πάμε αριστερά στο φύλλο $8$
  • Φύλλο $8$: $6 \le 8 \le 20$? ΝΑΙ → $\{8\}$
Βήμα 4: Δεξί Μονοπάτι (από [12] δεξιά)
  • $v = [19]$: $x'=20 > 19$? ΝΑΙ →
    • Αναφέρουμε ΟΛΟ το αριστερό υποδέντρο: $\{15, 19\}$
    • Πάμε δεξιά
  • $v = [23]$: $x'=20 > 23$? ΟΧΙ → πάμε αριστερά
  • Φύλλο $23$: $6 \le 23 \le 20$? ΟΧΙ → αγνοούμε
Αποτέλεσμα

Απάντηση: $\{8, 12, 15, 19\}$ ✓

6. Σύνδεση με 2D Αναζήτηση

Η 1D αναζήτηση είναι το θεμέλιο για τις 2D δομές:

  • kd-tree: Εναλλάσσει 1D αναζητήσεις μεταξύ x και y άξονα
  • Range Tree: Χρησιμοποιεί 1D δέντρα ως "συνοδευτικές δομές" σε κάθε κόμβο
Προηγούμενο Επόμενο: kd-Trees

Range Trees (Δέντρα Εύρους)

1. Εισαγωγή (Διαισθητικά)

👋 Εισαγωγή για Αρχάριους:

Τα kd-trees είναι μια χαρά, αλλά μερικές φορές δεν είναι αρκετά γρήγορα για συγκεκριμένες ερωτήσεις. Φανταστείτε ότι ψάχνετε ανθρώπους με ηλικία 20-30 ΚΑΙ μισθό 1000-2000€.

Το Range Tree είναι σαν ένα σύστημα με "Φωλιασμένους Φακέλους":

  1. Πρώτα έχετε ένα δέντρο που χωρίζει τον κόσμο με βάση την Ηλικία (Άξονας X).
  2. Σε κάθε κόμβο αυτού του δέντρου, αντί να έχετε απλά ένα όνομα, έχετε κρεμασμένο ένα ΟΛΟΚΛΗΡΟ καινούργιο δέντρο που οργανώνει τους ανθρώπους εκείνης της ομάδας με βάση τον Μισθό (Άξονας Y).

Είναι πιο "βαρύ" στη μνήμη (γιατί αποθηκεύουμε τα δεδομένα πολλές φορές), αλλά είναι αστραπιαίο στο να απαντάει σε ερωτήματα τύπου "Μέσα σε αυτό το ορθογώνιο".

Τα kd-trees είναι αποδοτικά για γενική αναζήτηση, αλλά για **ορθογώνια αναζήτηση εύρους** (orthogonal range search) σε 2 διαστάσεις, η πολυπλοκότητα είναι $\mathcal{O}(\sqrt{n} + k)$. Τα Range Trees προσφέρουν ταχύτερη αναζήτηση $\mathcal{O}(\log^2 n + k)$ με το κόστος περισσότερου χώρου μνήμης ($\mathcal{O}(n \log n)$).

Δομή Range Tree (2D):
  • Ένα πρωτεύον ισοζυγισμένο δυαδικό δέντρο στο $x$ (όπως το 1D tree).
  • Σε κάθε κόμβο $u$ του πρωτεύοντος δέντρου, υπάρχει ένα δείκτης σε ένα δευτερεύον δέντρο (associative structure).
  • Το δευτερεύον δέντρο περιέχει όλα τα σημεία του υποδέντρου του $u$, ταξινομημένα ως προς $y$.

Ψευδοκώδικας: Κατασκευή 2D Range Tree

function BUILD-2D-RANGE-TREE($P$)

  • Είσοδος: Σύνολο σημείων $P$.
  • Έξοδος: Ρίζα 2D-Range-Tree.
  1. Κατασκεύασε ένα ισοζυγισμένο δυαδικό δέντρο $T_{assoc}$ στο $P$ με βάση τα $y$-coordinates.
  2. Αν $|P| = 1$:
    • Επίστρεψε φύλλο που αποθηκεύει το $T_{assoc}$.
  3. $x_{mid} \leftarrow$ διάμεσος των $x$-συντεταγμένων (το $x$ του μεσαίου στοιχείου της ταξινομημένης λίστας).
  4. $P_{left} \leftarrow$ σημεία με $x_{coord} \le x_{mid}$.
  5. $P_{right} \leftarrow$ σημεία με $x_{coord} > x_{mid}$.
  6. $v_{left} \leftarrow$ BUILD-2D-RANGE-TREE($P_{left}$)
  7. $v_{right} \leftarrow$ BUILD-2D-RANGE-TREE($P_{right}$)
  8. Δημιούργησε κόμβο $v$ με τιμή $x_{mid}$ (το διαχωριστικό κλειδί).
  9. $v.left = v_{left}$, $v.right = v_{right}$.
  10. $v.assoc = T_{assoc}$ (βοηθητικό $y$-δέντρο).
  11. Επίστρεψε $v$.

Ψευδοκώδικας: Αναζήτηση Εύρους (Range Query)

function RECT-QUERY($v, [x_1, x_2] \times [y_1, y_2]$)

  1. Βρες τον κόμβο διαχωρισμού $v_{split}$ για το διάστημα $[x_1, x_2]$.
  2. Για κάθε κόμβο $u$ στο μονοπάτι από $v_{split}$ προς $x_1$:
    • Αν στρίψουμε αριστερά:
      Κάνε 1D-RANGE-QUERY στο $y$-δέντρο του δεξιού παιδιού ($u.right.assoc$) με $[y_1, y_2]$.
  3. Για κάθε κόμβο $w$ στο μονοπάτι από $v_{split}$ προς $x_2$:
    • Αν στρίψουμε δεξιά:
      Κάνε 1D-RANGE-QUERY στο $y$-δέντρο του αριστερού παιδιού ($w.left.assoc$) με $[y_1, y_2]$.
  4. Έλεγξε τα φύλλα στα οποία καταλήγουν τα μονοπάτια αν ανήκουν στο ορθογώνιο.
💡 Πολυπλοκότητα:
  • Χρόνος: O(log² n + k)
  • Χώρος: O(n log n) (γιατί κάθε σημείο αποθηκεύεται σε log n βοηθητικά δέντρα).

2. Λυμένο Παράδειγμα

ΕΞΕΤΑΣΙΑΚΟ ΘΕΜΑ: Κατασκευή Range Tree και αναζήτηση σε ορθογώνιο παράθυρο.

Παράδειγμα: Κατασκευή 2D Range Tree

Δεδομένα: $P = \{A(1,3), B(2,1), C(4,5), D(5,2)\}$

Σημείωση: Για τη διάμεσο, επιλέγουμε το $\lceil n/2 \rceil$-οστό στοιχείο της ταξινομημένης λίστας.

Βήμα 1: Πρωτεύον Δέντρο (x-coordinates)
  • Ταξινομημένα κατά x: $A(1,3), B(2,1), C(4,5), D(5,2)$
  • Διάμεσος-x (2ο στοιχείο): Σημείο $B(2,1)$ με $\mathbf{x=2}$
  • $P_{left} = \{A, B\}$ (x ≤ 2)
  • $P_{right} = \{C, D\}$ (x > 2)

Αναδρομικά:

  • $P_{left}$: $\{A(1,3), B(2,1)\}$. Διάμεσος-x (1ο): $A(1,3)$ με $\mathbf{x=1}$.
    • Αριστερά (x≤1): $\{A\}$ (Φύλλο A)
    • Δεξιά (x>1): $\{B\}$ (Φύλλο B)
  • $P_{right}$: $\{C(4,5), D(5,2)\}$. Διάμεσος-x (1ο): $C(4,5)$ με $\mathbf{x=4}$.
    • Αριστερά (x≤4): $\{C\}$ (Φύλλο C)
    • Δεξιά (x>4): $\{D\}$ (Φύλλο D)
Βήμα 2: Βοηθητικά Δέντρα (y-coordinates)

Σε κάθε κόμβο, δημιουργούμε BST με βάση τα $y$:

Κόμβος (Τιμή x) Σημεία Υποδέντρου Ταξινομημένα κατά y
Ρίζα (x=2) $\{A, B, C, D\}$ B(1) → D(2) → A(3) → C(5)
Αριστερό παιδί (x=1) $\{A, B\}$ B(1) → A(3)
Δεξιό παιδί (x=4) $\{C, D\}$ D(2) → C(5)
Βήμα 3: Range Query $[2, 6] \times [1, 4]$
  1. Split node στην Ρίζα (x=2), καθώς τα μονοπάτια για $x=2$ και $x=6$ διαχωρίζονται εδώ (το 2 πάει αριστερά, το 6 δεξιά).
  2. Μονοπάτι προς 2:
    Πάμε Αριστερά (x<=2) προς κόμβο x=1.
    Στον x=1, το range $[2,2]$ είναι δεξιά (ή ίσο), άρα πάμε Δεξιά.
    Φτάνουμε στο φύλλο B(2,1). Ελέγχουμε: $2 \in [2,6]$ και $1 \in [1,4]$ -> B OK.
  3. Μονοπάτι προς 6:
    Πάμε Δεξιά (x>2) προς κόμβο x=4.
    Εδώ το range $[2,6]$ καλύπτει πλήρως το αριστερό παιδί του κόμβου; Όχι ακριβώς, αλλά πάμε δεξιά για το 6.
    Ωστόσο, ως προς το εύρος, το υποδέντρο του x=4 είναι πλήρως εντός του [2,6] (x-coords: 4, 5).
    Άρα ελέγχουμε το y-assoc του x=4: $\{C(4,5), D(5,2)\}$.
    Ψάχνουμε y στο $[1,4]$.
    -> D(5,2): $y=2 \in [1,4]$ ✓ -> D OK
    -> C(4,5): $y=5 \notin [1,4]$ ✗
Αποτέλεσμα

Σημεία εντός $[2, 6] \times [1, 4]$: $\{B(2,1), D(5,2)\}$

3. Fractional Cascading

Με την τεχνική του **Fractional Cascading**, μπορούμε να βελτιώσουμε τον χρόνο αναζήτησης σε $\mathcal{O}(\log n + k)$, αποφεύγοντας τις επαναλαμβανόμενες δυαδικές αναζητήσεις στα δευτερεύοντα δέντρα.
